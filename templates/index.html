Vinted Reposter

Repost

Backups hold the full item JSON plus the original photos. “Restore” creates a new listing from a backup and deletes nothing.

Settings

Stored in settings.json on the state volume and applied immediately — no restart. The values in docker-compose.yml are only the starting point for the very first run; once a setting is saved here, the compose no longer affects it.

Set elsewhere, shown for reference

Container plumbing and the login come from docker-compose; the endpoints and the user agent are stored but rarely need touching.

Vinted credentials

Paste these from your browser while logged in on vinted.nl: DevTools → Application → Cookies. They are stored on the host in state.json and never sent back to this page. Leave a field empty to keep what is already stored.

Refreshing rotates the refresh token: Vinted issues a new one and kills the old. If the vinted-token-refresher container uses the same state folder, that is fine — they share this file. If it uses its own copy, update that one too, or it will lock itself out.
